# Mini-RAG

This is a minimal implementation of the RAG model for question answering.

## Requirements 

- Python 3.8 or later

#### Install Python using MiniConda

1) Download and install MiniConda from [here]()
2) Create a new environment using the following command: '''bash $ conda create -n Mini-RAG-App python = 3.8'''
3) Activate the environment: '''bash $ conda activate Mini-RAG-App'''
